Quick-load a value with | marking the cursor, or [...] marking a selection (a selection is what #0 picks up). E.g. 12|34 or 2[3]4. Index-based, so it's exact for flat digit/letter sequences; for LaTeX containing braces, use the value/position fields below instead, or drive window.mf from the console.

Insert Template

Runs executeCommand(['insert', template]) against the current cursor/selection. #@ / #& are the implicit before/after arguments (atoms adjacent to the cursor, not requiring a selection); #0 is the current selection (or a placeholder if none); #? is always a placeholder. Click a preset to fill it in and run it immediately.
