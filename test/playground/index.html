Quick-load a value with | marking the cursor, or [...] marking a selection (a selection is what #0 picks up). E.g. 12|34, 2[3]4, 123^{|45} or \mixfraction{1}{2}{3}|. The marker is placed by searching for the offset that renders back to exactly what you typed, so it lands correctly inside nested structures too; it falls back to index-based parsing when no offset matches.

Insert Template

Runs executeCommand(['insert', template]) against the current cursor/selection. #@ / #& are the implicit before/after arguments (atoms adjacent to the cursor, not requiring a selection); #0 is the current selection (or a placeholder if none); #? is always a placeholder. Click a preset to fill it in and run it immediately.

Delete & Cursor

Runs the command against the live field. Backspace is Casio-style: a press always removes something, folding the old navigate-only steps into the delete that follows. The …Loop cursor commands wrap around the ends of the field instead of stopping there.

Delete scenarios

One card per case: a start state, then the state expected after each Backspace. Load puts the start state in the field above, Step presses Backspace once so you can watch it happen for real (the row you're on is highlighted), and Run plays the whole case at once.

Live State

marked is the current value with | at the cursor, or [...] around a selection — same syntax as the quick-load box above, but derived from the real cursor/selection so it lands correctly even inside nested structures, e.g. 123^{4|5}.
